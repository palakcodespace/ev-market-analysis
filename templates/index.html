End-to-End Data Pipeline Architecture

The platform enforces clean separation of concerns, ensuring reproducible data ingestion, 3NF normalization, SQL-based metric computation, and accessible user presentation.

  • 1. Data Ingestion: IEA Global EV Data, EV-Database specs, Customer survey benchmarks CSV / JSON
  • 2. Preparation & Audit: Missing value imputation, outlier bounds, deduplication Pandas / NumPy
  • 3. Database Storage: 3NF Schema (6 tables, PK/FK constraints, indexes, 6 analytical views) {{ db_mode }}
  • 4. Presentation Layer: Responsive Flask Web App + Plotly.js interactive charts + Tableau embeds Bootstrap 5
